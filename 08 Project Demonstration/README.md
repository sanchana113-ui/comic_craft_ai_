# 8. Project Demonstration

## Goal

Demonstrate the complete path from a story premise to a five-panel comic preview and downloadable PDF.

## Walkthrough

1. Start the app using the instructions in `05 Project Development/README.md`.
2. Open `http://127.0.0.1:8000/`.
3. Enter the premise, character, setting, tone, and art style.
4. Generate the comic and show the five panels, text, and illustrations.
5. Download and open the PDF to show the cover and panel pages.
6. Optionally demonstrate the JSON route or describe service fallback behavior.

## Demo Materials

The original workspace may contain a screen recording and generated PDFs/images. They are intentionally not copied into this clean project folder; generated artifacts are runtime output, and the recording may be large. Add selected demo assets only if the submission requires them. Do not include `.env` or credentials.

## Presentation Checklist

- Confirm the development environment is installed and the app starts.
- Confirm the example prompt produces five panels.
- Confirm the PDF opens.
- Explain fallbacks if an external service is unavailable.
- Keep API keys and private environment files off screen.
